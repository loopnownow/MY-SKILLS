💡 技能图谱优化与未来演进建议（请选择感兴趣的方向）

针对当前的科研与工程构件，梳理了以下 5 个维度的拓展建议：

1. 一键式 Pipeline 联动（全自动数据到论文草稿）
将 `02_data-processing` (影像预处理) -> `04_analysis` (统计分析) -> `05_manuscript` (自动生成 Table 1 & STROBE 流程图) 整合为单命令 CLI 自动化工作流。
2. 增强型 Radiology & Nature 审稿人 Agent 反溃机制
结合 `06_review` 中的 pre-submission hard gates，构建模拟顶刊 Reviewer 提问的预审 Prompt 库，提升一审通过率。
3. 本地 LLM Agent (AnythingLLM / Ollama) 拓扑自动同步
自动建立 `SKILL.md` 索引钩子，在本地 agent 调用时按需动态加载 Python 脚本与领域 References 规范。
4. 临床伦理批件与 ClinicalTrials.gov 结构化建档拓展
扩展 `02_data-processing/ethics-application-forms`，实现知情同意书 (ICD) 及伦理审查申请表的规范化一键替换生成。
5. 智能化 Skill Harvest 收益追踪 (ROI Counter)
自动根据 Python 脚本执行日志更新 `roi-ledger.csv`，按月生成技能调用效率提升分析报告。
