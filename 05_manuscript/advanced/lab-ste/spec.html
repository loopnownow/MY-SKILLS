3. 规则速查（23 条）

EN-S01句长must
语言 / 场景
en；Methods 步骤句用 sentence_words_step_max，描述句用 sentence_words_desc_max。
检测
按空白切词，计词数。步骤句启发式：句首动词，或含 then / 序号。
严重度
超过步骤上限 must_fix；超过描述上限 should_fix。
正例
We drew a region on the largest slice.
反例
We then carefully and subsequently performed the drawing of a region of interest on the slice that was considered to be the largest after a visual comparison of adjacent slices.
豁免
纳入/排除标准的分号列表可按配置改用描述上限。
EN-V01语态should
语言 / 场景
en。默认主动；施动者不重要或不可知时保留被动。
检测
结构：be + 过去分词。Methods 被动比上限按档案的 methods_voice 取键：ste_active 用 passive_ratio_methods_max_ste_active，conventional_passive 用 passive_ratio_methods_max_conventional_passive（映射在 passive_ratio_key_by_voice）。其他档案用 passive_ratio_other_max。
严重度
有明确施动者仍用被动 → should_fix。
正例
Two readers drew the region. / Patients were randomized.
反例
The region was drawn by two readers.（施动者已知且重要）
豁免
配置 methods_voice: conventional_passive 时，Methods 被动不因本条必改。该开关用于对齐 05 现行体例，与本条默认不同，冲突见 §8。
EN-L01一词一词性、一词一义must
语言 / 场景
en；manuscript-methods-en 对批准词典做覆盖检查。manuscript-id-en 默认关闭覆盖，只做概念别名检查。
检测
词表；一词多 POS 以词典行的 pos 为准，同形不同类须分行。未登录词且不在术语锁定、数字、专名中 → 命中。
严重度
未登录词 should_fix；同一概念两个未锁定写法 must_fix。
正例
全文只用 use，不用 utilize。
反例
上一段 use the tool，下一段 utilize the tool。
豁免
术语锁定；软件界面字符串。
EN-VB01动词：少短语动词、少多义、少名词化must
语言 / 场景
en。
检测
短语动词表计数 / 千词；名词化表正则；perform/conduct/make/take + a/an + 名词。改写目标动词（如 analyze、evaluate、extract）已在批准词典。名词 analysis 可用，但不得接 perform、conduct、carry out。
严重度
名词化 must_fix；短语动词超阈 should_fix。
正例
We extracted features.
反例
We performed an extraction of features. / We carried out the analysis.
豁免
固定方法名（若已锁定）。
EN-R01指代must
语言 / 场景
en。
检测
It/This/These 独立作主语。需要前一句有唯一名词先行语。
严重度
must_fix。
正例
The nomogram had a higher AUC. The nomogram did not calibrate in the test set.
反例
The nomogram had a higher AUC. This was not adequate.
豁免
This study 在摘要首句若档案允许；默认 Methods 不允许。
EN-N01名词串should
语言 / 场景
en。
检测
连续名词（不含 of 结构）个数 > noun_stack_max。
严重度
should_fix。
正例
score of radiomics features
反例
radiomics feature selection model performance score
豁免
已锁定多词术语按一个词计。
EN-T01时态should
语言 / 场景
en。
检测
Methods/Results 以过去时为主；普遍事实现在时。tense_mix_same_subsection 为真时，同一小节同时出现过去时限定动词与现在时限定动词即 should_fix。
严重度
should_fix。
正例
We fitted the model. A byte has eight bits.
反例
We fit the model and report that patients are being scanned tomorrow.（步骤与未发生的事混在一句）
豁免
figure_present_tense_ok 为真时，Figure N shows 允许现在时。
EN-C01从句与 whichmust
语言 / 场景
en。
检测
从句数 > subordinate_clauses_max；非限制性 which 计数。
严重度
多从句 must_fix；补充性 which should_fix。
正例
We used logistic regression. Age was a covariate.
反例
We used logistic regression, which was selected after a comparison that included age, which was coded as a continuous variable.
豁免
限制性 that 从句一条以内。
ZH-S01句长与逗号子句must
检测
句号/问号/叹号切句；汉字数 > sentence_chars_max（review-comment-zh 用 sentence_chars_comment_max，由档案的 sentence_chars_key 指定）；逗号切分的子句数 > comma_clauses_max。
严重度
must_fix。
正例
在 Methods 第二段写明连续入组。
反例
在仔细阅读全文并对照结果页之后，建议作者在方法、结果与讨论三处同时补充连续入组、排除标准与流程图，从而使读者能够理解队列是如何形成的。
豁免
引用整句；批注修改建议行中引号内的补写文本（按引文跳过）。
ZH-SUB01主语完整must
检测
连续无主语句段（逗号或句号后无名词/代词主语）长度 > dropped_subject_run_max。
严重度
must_fix。
正例
作者未报告扫描参数。作者也未报告重建核。
反例
未报告扫描参数，未写重建核，未给 b 值，未说明方向数。
豁免
祈使句批注的修改建议行（见 CM-01）允许无主语句。
ZH-R01指代must
检测
该/其/此/这 + 名词或单独 其。前一句必须能唯一对齐对象。
严重度
must_fix。
正例
列线图的 AUC 为 0.84。列线图在测试集未校准。
反例
列线图和临床模型都报告了 AUC。其并未校准。
豁免
该研究 作为标题后首句，若对象唯一。
ZH-NOM01名词化must
检测
词表 进行/开展/实施/做出 + 动词性名词。
严重度
must_fix。
正例
提取特征。
反例
进行特征提取。
豁免
法规或指南固定搭配（须写入术语锁定）。
ZH-DE01长定语should
检测
同一名词短语内 的 连续嵌套层数 > de_nest_max。
严重度
should_fix。
正例
测试集上的 AUC。该 AUC 来自联合模型。
反例
来自联合模型的测试集上的未经校准的预测概率的均值的差异。
豁免
机构正式名称。
ZH-BEI01被动should
检测
被 字句。有明确施动者且施动者重要 → 改主动。
严重度
should_fix。
正例
两名医师勾画病灶。 / 患者被随机分组。
反例
病灶被两名医师进行了勾画。
豁免
施动者未知。
ZH-Q01量化must
检测
模糊词表（较大、明显、一定程度 等）。
严重度
must_fix。
正例
测试集 AUC 比临床模型高 0.07。
反例
测试集表现有较大提升。
豁免
词表 exempt_if 列。
ZH-ID01书面套话与四字格should
检测
成语/套话表密度 / 千字。
严重度
超阈 should_fix。
正例
这项研究是单中心回顾。
反例
本研究应运而生，具有至关重要的临床意义。
豁免
患者原文引语。
ZH-TERM01术语对照must
检测
课题术语表。首次：全称 + 缩写；此后只用缩写。中英混用别名计数 > 1 → 不一致。
严重度
must_fix。
正例
intravoxel incoherent motion (IVIM) 首次，其后 IVIM。
反例
同段交替 IVIM / 体素内不相干运动 / IVIM 成像。
豁免
题名可保留全称。
ZH-PUN01标点与数字单位should
检测
中文语境出现 ASCII , . : 作句读；数字与单位之间空格策略与全文不一致。
严重度
should_fix。
正例
间隔 2 mm。
反例
间隔2mm,然后重建.
豁免
英文专名、DOI、代码。
AI-L01词汇层must
检测
词表命中 / 千词（英）或 / 千字（中）。
严重度
阈值为 0 的条目 must_fix；其余超阈 should_fix。
正例
We used logistic regression.
反例
We leveraged a pivotal framework to delve into the tapestry of the data.
豁免
行内 exempt_if。
AI-S01句式层should
检测
三段并列；不是……而是…… / not X, but Y；段首空总述；空泛升华结尾。
严重度
should_fix。
正例
测试集未做外部验证。
反例
这不仅是方法问题，而是关乎未来诊疗格局的深刻命题。
豁免
真纳入/排除三条（计数器不记这类规定列表）。
AI-D01篇章层hint
检测
连续段首句式相同超过 para_openers_same_pattern_run_max；段落长度变异系数低于 para_length_cv_min；以总结句收尾的段落比例过高。
严重度
hint（误报高，先提示）。
正例
长短段混排，段首动词变化。
反例
每段都以“综上所述，本研究表明……”收尾。
豁免
Methods 逐步操作可以同构（档案可关此条）。
AI-F01格式层must
检测
破折号密度、加粗密度、额外小标题、列表占比。
严重度
破折号在 emdash_must_fix_profiles 所列档案（默认两个稿件档案）must_fix；其余档案和其余子项 should_fix。
正例
中文批注连续成段，一条一个问题。
反例
一条批注拆成五个加粗小标题加项目符号。
豁免
IMRAD 规定标题；真枚举。
CM-01批注五槽must
语言 / 场景
zh；review-comment-zh。
检测
先按 source_tag_strip 剥文首来源标签，再按 comment_schema.slots 用句号切槽。槽 1 匹配 location_patterns；只命中 location_coarse_patterns 为过粗。槽 3 以 basis_prefix 开头，且须命中 basis_source_patterns（规则 ID 或数据源）。槽 4 首词在 action_verbs 内，且不含 vague_phrases。槽 5 为三档严重度之一。槽 2：句号数大于 multi_problem.max_sentences，或命中 conjunction_re，判一条多问。
严重度
缺槽、顺序错、位置两表都不中、建议不可执行、一条多问 must_fix；位置过粗 should_fix。
豁免
引号内的补写文本不计句长。Word 作者字段由 word_author_field 固定，不属本条检测。来源标签剥掉后不参与切槽。

8. 验证指标

指标算法要点
平均句长词或字，按语言
超长句比例相对对应上限
术语一致率1 −（同概念写法数−1）/ 出现次数
被动句比例be+V-ed 或“被”字句 / 句数
名词化命中数词表
去 AI 命中 / 千词或千字分层：词汇/句式/篇章/格式
语义保持改写前后数字、锁定术语、否定词集合不变
词典覆盖率（批准词典 + 默认锁定 + 课题锁定命中词）/ 总词数，只在 manuscript-methods-en 计算
例句自检规范正例全部通过词典与锁定表（tools/check_spec_examples.py）
误报率人工抽样；反向改配置，不改事实

没有指标就不能改阈值。语义保持失败视为冲突层 1–2 失败，不得用 STE 或去 AI 分数开脱。
