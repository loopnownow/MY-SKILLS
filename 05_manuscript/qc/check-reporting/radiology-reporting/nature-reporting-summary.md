# Nature Reporting Summary (pointer)

Short logistics note for Nature-portfolio submissions. **No checklist item dump.**

When the target is a Nature-portfolio journal (Nature Medicine, Nature Biomedical Engineering, Nature Communications, npj Digital Medicine, Nature Machine Intelligence, etc.):

1. Complete the journal’s **Reporting Summary** (published with the article) and, if requested, the **Editorial Policy Checklist**.
2. These are a **disclosure layer on top of** the primary reporting-guideline stack (CLAIM / TRIPOD+AI / CLEAR / STARD / …) — not a substitute.
3. Manuscript **shape** (unstructured abstract, Extended Data split, Methods placement) → `05_manuscript/base/write-venue/radiology-writing/nature-family-shape.md`.
4. Gate / venue minima → `05_manuscript/qc/venue-compliance-minima.md` (+ `venue-currency.md`).
5. Full imaging-AI / radiomics stacks → sibling `guideline-router.md`. Gate must-check subset → `05_manuscript/qc/reporting-guideline-route.md`.

Verify live author instructions per venue before finalising word limits and checklist filenames.
