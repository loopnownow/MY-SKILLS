## Checklist

| id | Check | Fail → |
|---|---|---|
| VC-1 | Exact venue, year/cycle, track, article type, stage identified | 03 / 05 |
| VC-2 | Official source URL + date checked recorded (`venue-currency.md`) | 03 / 05 |
| VC-3 | Official template/form used where required (scaffold ≠ official) | 05 |
| VC-4 | Page-limit scope understood (what counts / excluded) | 05 |
| VC-5 | Required statements / checklists / disclosures present | 05 |
| VC-6 | Blind-review files + PDF metadata checked for identity leaks (pairs `anti-leak-placeholders.md`) | 05 |
| VC-7 | Figures/tables legible at print size | 05 |
| VC-8 | References / appendices / supplements follow **current** venue rules | 03 / 05 |
| VC-9 | PDF / source package compiles or exports cleanly when applicable | 05 |
| VC-10 | Submission-portal preview reviewed before final submit (Bai portal; not this gate's job to click) | user / Bai |

**PASS:** VC-1–10 clean or Word-commented.
**FAIL:** missing currency note or identity-leak risk → rollback **05** (and/or 03 find-journal re-check).
