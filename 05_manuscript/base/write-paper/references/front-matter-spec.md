# Front matter and submission slots

Fill these before drafting body prose; every slot names its source, and an unfilled slot
stays an explicit placeholder (typography and title-page DOCX defaults live in
`05_manuscript/advanced/Aitor-format.md`).

## Title and running title

- Title: one noun phrase naming **modality + model/method + endpoint**; no colon, no
  abbreviation.
- Keep the endpoint name **identical** in the title, the abstract Purpose, the Methods
  outcomes subsection, and the last Introduction paragraph.
- Running title: ≤50 characters, no abbreviation, no colon.

## Authors, affiliations, corresponding author

- Authors in `Given Family` order, affiliation superscripts matching the affiliation list,
  corresponding author marked with an asterisk.
- One affiliation line per institution: `Department, Institution, Street address, City
  postcode, Country`.
- Corresponding author block: name, e-mail, postal address.
- Equal contribution / current address notes only when the author confirms them.

## Fixed label slots (bold label + supplied value)

| Slot | Content rule |
|---|---|
| `Funding:` | grant name + number, and the named author it went to; write `None` when there is no funding — never invent a number |
| `Ethics:` | approving body full name, approval date, approval number, consent model (obtained / waiver + basis), Declaration of Helsinki; the approval period must cover the data-collection period |
| `COI:` | author-confirmed statement; default text only when the author confirms no conflicts |
| `Acknowledgments:` | named contributors who do not meet authorship |
| `Author contributions:` | CRediT-style roles; use the owner's three-role template (writing original draft / data collection / statistical analysis; conceptualization / writing-review and editing / correspondence) and confirm each name |
| `Data availability:` | minimal dataset needed to interpret and replicate, with DOI/accession where available |
| `Code availability:` | repository + version/DOI, or `available from the corresponding author on reasonable request` when the author confirms |

## Highlights (when the venue asks)

Three bullets, one sentence each, endpoint allowed, **no numbers**; order them as main
finding → incremental or comparative value → later endpoint or clinical use.

## Abbreviations and keywords

- Abbreviations list: alphabetical; include a term only if it appears **at least twice**
  in the body; expand at first use in the body.
- Keywords: 5-8 terms, lowercase unless a proper noun; use the venue's separator (semicolon
  by default) and do not repeat title words mechanically.

## Ethics slots are read, not reconstructed

Type an approval date or number only after reading it from the approval letter. When the
letter is not available, leave the slot, raise a Word comment (author **A**) with the exact
question, and fill it before submission. The same rule applies to consent wording: state
the model the committee actually granted, not the one the template suggests.
