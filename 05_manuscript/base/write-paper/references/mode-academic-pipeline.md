# Generic academic paper pipeline (outline)

Condensed planning modes for non-imaging or cross-disciplinary outlines. Imaging prediction
full papers prefer `pipeline-stages.md`. Language polish → `humanize`. Reviewer
response → `revise`.

## Priority

Supplied facts > venue format > generic English. Do not invent results or citations.

## Modes

| Mode | Trigger | Output |
|------|------|------|
| `full` | Draft the paper | Full draft from supplied facts |
| `plan` | Uncertain structure | Chapter plan |
| `outline-only` | Outline only | Outline + evidence map |
| `revision` | Revise body after review | Revised prose (the letter itself → `revise`) |
| `abstract-only` | Abstract only | Abstract + keywords |
| `lit-review` | Review article | Annotated synthesis (`meta-analysis`) |
| `citation-check` | Check citations | Citation audit (`verify-refs`) |

Default when unsure: **`plan`**.

## Stages (full)

```
0 CONFIG   type / field / venue / citation style / existing materials → confirm
1 RESEARCH search strategy + pool (skip if the user brought the library)
2 ARCH     structure + outline + evidence map → confirm
3 ARGUMENT claim-evidence chain
4 DRAFT    section drafts (do not invent data/citations)
5 CITE     format + DOI check
6 REVIEW   self-audit → `self-review`
7 FORMAT   venue shape in this pack (`radiology-writing/`, `radiology-polishing/`)
```
