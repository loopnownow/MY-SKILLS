# 复旦大学附属金山医院 — 伦理材料包栏目要点

基于 `填写好` 样例包归纳，填报时以**现场模板**为准，本文件作字段核对清单。

## 0. 科研伦理审查申请材料登记表.xls

| 列意 | 填法 |
|------|------|
| 课题编号 | 自选课题填「无」 |
| 经费来源/预算 | 无经费可不勾 |
| 课题类型 | 自选课题 / 院级等 |
| 题目、负责人、科室、职称、电话 | 必填 |
| 项目来源、其他单位 | 本院 / 无 |
| 研究期限 | 具体到日 |
| 招募人数、中心数 | 本院人数；单中心=1 |
| 方案/ICF 版本号与日期 | 初始 V1.0 + 自拟日期 |
| 递交材料清单 | 罗列实际上交文件 |

## 1. 伦理审查初审申请表.docx

- 项目名称、是否被拒/暂停、组长单位  
- PI、科室、联系人电话邮箱  
- 资金来源（自筹等）  
- 拟招募人数、试验期限  
- 研究类型：药物/器械/试剂/**其他（治疗性·观察性·…）**  
- 多中心、受试者状态、年龄  
- **弱势群体**（孕妇等）  
- 保密方式、生物样本外送  
- 知情同意过程（谁解释、何时、场所、招募广告）  
- 不识字/无行为能力、人遗  
- **急救及防范措施**（须按本研究风险重写）  
- PI 签字栏  

## 1b. 立项申请表.doc

- 申请日期、项目名称、负责人、职称、科室、联系人  
- 项目类别（自选/纵向/横向）  
- 经费、单中心/多中心、总样本/本中心样本  
- 探索/验证；**干预 vs 观察**  
- 额外检查、EDC、保险、人遗  
- 起止时间  
- 主要研究人员表  
- 研究简介 / 目的 / 内容  
- PI 申明、科室意见  

## 2. 研究方案模板.doc

建议保留院方章节骨架，替换正文：

1. 封面（题目、单位、科室、PI、电话、起止、来源）  
2. 方案签字页  
3. 研究背景 + 参考文献  
4. 研究目的  
5. 研究概况（设计、例数、流程图）  
6. 研究人群（入排）  
7. 终点  
8. 研究过程  
9. 不良事件  
10. 数据管理  
11. 招募与知情同意  
12. 统计与样本量  
13. 保密  
14. 进度  

干预研究：写清随机、对照、盲法限度、干预细节、安全审核。  
数字健康/AI：版本锁定、脱敏、日志、人工审核。

## 3. 知情同意书.docx

- 方案名称、版本、研究者  
- 背景、目的、过程（人数、入排、步骤、时长）  
- 风险与受益、费用与补偿  
- 备选方案、权利、联系方式（研究者 + 伦理办）  
- **签字页表格勿删**

## 4. 研究者简历.docx

表格式：姓名、性别、出生、学历、职称、职务、专业、电话、邮箱、教育、工作、GCP、既往试验。  
未知项写「待补充」，勿编造。

## 5. 主要研究者声明.doc

替换科室 + 题目即可，声明条文一般不动。

## 6. 课题组成员名单.doc

表头：序号、姓名、性别、职称、职务、单位、分工。  
仅知 PI 时只填一行，其余留空并在说明中标注待补。

## 常见错误（样例残留）

- 旧 PI/科室/电话仍在联系行  
- 仍勾「观察性」而方案是 RCT  
- 弱势群体仍勾「无」但对象为孕妇  
- 急救措施仍是「停止影像学检查/给氧」等无关表述  
- 知情同意仍写「不涉及干预/仅病历回顾」
