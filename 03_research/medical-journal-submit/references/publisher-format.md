## Cost advice

- If the user wants to avoid APC, prefer hybrid titles and submit as subscription / toll-access when the journal allows it.
- Check institutional Read and Publish agreements (Springer Nature, Elsevier, Wiley, OUP, BMJ, PLOS CAP) before paying.
- Waivers for low-income-country corresponding authors exist at BMC, PLOS, Frontiers, MDPI, and many societies. Apply at submission when required.
- Page charges and color-print fees on older society hybrids are separate from APC. Read the charges paragraph, not only the OA page.

## House style shortcuts

Only apply after the live author instructions are fetched. If instructions conflict with this page, the journal wins.

- Clinical medicine default reference style is Vancouver / ICMJE.
- Structured abstract is the default for original articles.
- Reporting guidelines follow EQUATOR (CONSORT, STROBE, PRISMA, STARD, TRIPOD, ARRIVE, CARE).
- Trial registration number belongs in the abstract and methods.
- Figure files are almost never allowed as screenshots of tables.
