# Graylist (mounted)

Journals the lab does **not recommend** for new submissions, but that are not hard-banned.

- File: `graylist.csv` / `graylist-names.csv` (copy: `artifacts/灰名单_不推荐.csv`)
- Tier order: **blacklist** (never) → **graylist** (not recommended) → normal pool → **whitelist-submitted** boost → **BMC/Medicine** pattern boost
- Default Phase-1/2 tables: **omit** graylist titles unless the user asks to include them
- If included on request: mark 「灰名单/不推荐」; never boost; never auto-fill
- Never promote a graylist title into whitelist-submitted without explicit user approval
- Blacklist always wins: if a title appears on both, treat as blacklist

User fills the list; seed is empty until they name titles.
