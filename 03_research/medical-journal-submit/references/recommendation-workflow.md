# Recommendation workflow

## Mounted blacklist

PLoS One, Scientific Reports, MEDICINE (LWW Baltimore). Never recommend.

## Every paper: three layers, five each

Order of tables

1. 层2 — Q1, IF<5 — 5本
2. 层3 — Q2 — 5本
3. 层2补 — Q1, 5≤IF≤10 — 5本

Score inside a layer by match, annual articles, then 易投指数.

## Two phases

Phase 1: three 5-row tables, no live AIM/fee lookup.
Phase 2: only confirmed titles.
