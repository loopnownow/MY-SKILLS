# 指针与落库同步

库里的实体、index 的一行、项目侧的指针是同一篇的三个位置；改一处必须三处同改。同步规则只服务于一件事：引用能落到实物。

## 指针形态

- 指针 `DOI_<doi>.md` 与实体同目录同级；DOI 的 `/` 落盘转 `_`，例：`DOI_10.1016_s0140-6736(10)60279-6.md`。
- 指针 `.md` 与实体 `.pdf` 同名不同扩展名，是设计，不要统一成同名文件。
- 无 DOI 件 `NOID_<sha8>_<slug>.pdf` 归 `other/theses`，入 index 后 `_library/INDEX.md` 计数同步。

## DOI 修正三段同步

缺任何一段即断链：

1. rename 实体 PDF（新名 = 更正后的 DOI，`/` 转 `_`）。
2. 改 `references\index.csv` 的 `rel_path`。
3. 改指针 `DOI_<doi>.md` 的文件名与文内链接。

三段必须在同一次操作里做完。只改实体不改指针 = 断链；只改 index 不改实体 = 假绿。

## 断言纪律

改名前先断言两件事：旧文件存在、新名不存在。任一不成立即停，先查清是重复件还是命名冲突，不猜。

## 文本保真

读写 index、指针、台账时用 `newline=''`，按原 EOL 回写；不改 CRLF、不加 BOM。文本行被改动会在 diff 里放大成整文件变更，后续无法分辨真实修改。

## 变更台账

每次改 DOI 或文件名，记一行 from / to / sha256。台账是本轮唯一可回溯记录，不靠记忆。

## 目标刊参考格式判据

改引用格式时按目标刊判据抽查 5 条：正文编号 `[n]` 非上标；作者全列、不用 et al；末两位作者用 and 连接；条目内不写 doi、PMID、PMCID；刊名按 PubMed 缩写。EndNote output style 与该刊对齐，不手搓风格。

## 过程

1. 三处对齐做集合差：DOI 清单台账、稿件引用、指针目录。
2. 逐条核验：命中项比对 rel_path 与 sha256；未命中项定态；不确定记 `unchecked`。
3. 格式落目标刊抽查 5 条（作者数、标点、缩写、是否出现 doi 或 PMID）。
4. 改 DOI / 文件名走三段同步，先断言后改名。
5. 重跑 `validate_citations.py` 与 `retraction_scan.py`；结束核 index 行数与磁盘实体数相等。
6. 变更记台账（from / to / sha256）。

## 注意事项

- 同一 DOI 在不同 layer 是不同键，不合并。
- 只改实体不改指针 = 断链；只改 index 不改实体 = 假绿；三段须同一操作完成。
- 指针 `.md` 与实体 `.pdf` 同名不同尾是设计，不要统一。
- 不编 DOI；抓不到记 `unchecked`，不写推测值。
- `retraction_scan.py` 每轮必跑，命中即降级，不沿用上一轮的 PASS。
- 语料 PDF 正文不抽，只核元数据与落点。
