# 申请包与收件归档

伦理申请与基金申请共用的打包口径：一个资助方一套文件、申请包按审查顺序编号、收件原样归档、附件成套性可计数。

## 一申请包一资助方

不同资助方的模板字段不同，不能合并成一份再拆：市卫健委经费编制版（docm）、院青年启动基金（doc）、同名研究（ppT）是三套字段，混填即字段错位。按资助方各建一份，公共内容（研究方案、ICF）引用同一份，不复制。

## 伦理申请包编号

编号即审查流程顺序，收件方按号判断完整性：

| 序号 | 文件 |
|---|---|
| `0-立项申请表.doc` | 立项 |
| `1-初始审查申请表.docx` | 初始审查 |
| `人员信息汇总.xlsx` | 人员 |
| ICF | 知情同意书 |
| 研究方案 | 方案正文 |

编号只表达顺序，不是版本号；改稿按日期戳目录另存，不覆盖原号。

## 收件归档

- 收件落 `ref\refer\incoming-YYYYMMDD\_root\`：原样收件，同名不同版并存不覆盖。
- 改稿与收件分目录，避免"最新版"被收件件混掉。
- 简历与 GCP 证书单独子夹、按人编号：`1-姓名/`、`2-姓名/`。

## 批件可引用性按日期切点判

- 批件日期在现行切点之后（含切点）→ 可挂新申请。
- 更早的批件移出申请包，不删。
- 日期读不出或编号未知 → 标 `待判`，不按文件名里的年份猜（例：`SCCIRB2004216` 按编号读作 2020 是猜测，不是证据）。

## 附件成套性核对

按四类计数核对：批件、方案、ICF、其他。缺类即补；缺项在清单里标 `待补`，不留空。完成形式写可计数指标（如"附件 6 件、四类齐"），不写"已完成"。

## 过程

1. 列资助方清单，一资助方一份文件，记下各自模板字段。
2. 先填简表，再填正文；摘要固定 400 字，结构为 目的 → 人群/干预 → 主要结局 → 预期交付。
3. 四个 slot 固定写：3–4 条研究目标、3 条创新点、编号研究内容、技术难点与研究内容一一对应；立题依据按 现状 → gap → why now 写。
4. 附件成套性检查，缺项标 `待补`。
5. 伦理包按 `0-` / `1-` 编号排，人员材料按人编号。
6. 收件与改稿分目录；完成形式写可计数指标。

## 注意事项

- 混两个资助方的口径等于字段错位，宁肯多一份文件。
- 旧批件不挂新申请；日期读不出标 `待判`，不按文件名年份猜。
- 伦理材料含 PHI 时只列文件名与路径，不摘 ICF 正文；`raw-*/**/*.txt` 可能是 OCR 侧车，不当原件归档。
- 不编基金号、伦理号、批准日期；没有就留空并标待补。
- 完成形式写可计数指标，不写形容词。
