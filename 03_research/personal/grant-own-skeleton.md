# 自拟标书章节骨架 — Voice B（写自己的）

**这是写自己的国自 / 市科委 / 卫健委 / 院级 / 开题 / 临床研究方案。**
评别人的国自 → `references/radiology/grant-review.md`（Voice A）。不要把「创新性有限」「可行性欠佳」写进本稿。

占位：`[Title]` `[疾病]` `[表型]` `[技术]` `[n]` `[PI]` `[假说]` `[动物模型]` `[平台]`。
不写未刊患者级结果表、伦理批件扫描、电话、申请人通路全文。

官方小节标题不要删；下面是往里面填的节奏。

## 文类与提纲（照官方标题填）

| 文类 | 骨架（不要删官方标题） |
|---|---|
| 国自青年/面上 **报告正文** | （一）立项依据与研究内容 → 研究目标/关键科学问题 → 方案及可行性 → 特色与创新 → 年度计划及预期结果 → （二）研究基础与工作条件 |
| 国自 **摘要**（中英各一段） | 负担/缺口 → 前期发现 → 假说 → 拟用方法与验证 → 预期理论/临床意义 → 关键词。句式见 `grant-writing.md` |
| 市科委 **可行性方案** | 趋势判断和需求分析（国内外现状+创新点）→ 研究内容/技术关键/实施方案 → 执行年限和计划进度 → 现有工作基础和条件。创新两栏提前到第一部分 |
| 市/区卫健委 **申请书正文** | 与国自正文几乎同构；年度计划按半年块写「完成 [n] 例 / 完成 XX 检测」；区级把目标写成可测指标 |
| 院级/青启 **申请书、任务书** | 立论依据 → 目的及意义 → 课题设计（内容/方法/路线/关键）→ 研究基础 → 完成指标（文章档次+人才培养） |
| 伦理包里的 **临床研究方案** | 目的 → 方案（入排/终止/干预/结局/统计）→ 研究基础。知情同意表走 ethics 技能 |

PPT、预算表、财务、合同扫描、职称/人才表、已填伦理包、图像、Excel 数据：不进本技能正文。

## 立项依据：固定五步

1. **疾病负担 + 分型/分级**。先把对象说清（含亚型对照）。给 1–2 个流行病学数字即可，不要堆综述。
2. **主流学说及其缺口**。典型句式：传统假说「不能解释」[指标]与临床表现相关性差、常规治疗不佳、指标正常仍发病。缺口要具体，避免「尚未完全阐明」空转。
3. **前期工作（文献 + 自己）**。「文献和我们前期工作均显示」「我们前期研究发现」。临床现象 → 影像/组学证据 → 动物或离体验证，三条链至少两条。
4. **假说一句**。「故推测…可能是…的主要和起始因素」；或「基于前期研究提出如下假说：…是由 A 与 B 共同驱动的 C」。
5. **本研究要做什么**。无创影像 / 标记代谢 / 多模态机器学习 + 动物（或细胞）验证。落到「完善发病机制 / 提供诊断分级方法 / 有助于治疗」。

立项小节标题用**机制节点**而不是方法名。方法创新和技术缺口（例如 1H-MRS 不能定量）写进立项，不要只放在创新栏。方法升级怎么写 → `radiology-frontier` `method-upgrade-into-grant.md`。

市科委可行性方案把「国内外现状」和「学术思想创新 / 技术方法创新」提前到第一部分，立项里少写目标句。

## 研究内容 / 目标 / 关键问题

**研究内容**用可执行动词 + 对象 + 方法，编号 (1)(2)(3) 或 1.1/1.2。
- 动物段固定顺序：造模 → 行为认知 → 影像/波谱 → 组学或酶/病理 → 统计。
- 临床段：入组量表判定表型 → 扫描/采样 → 组间比较与相关。

**研究目标**改成「确定 / 阐明 / 探讨」三档（不要把探讨当唯一目标）：

| 档 | 用在 | 例（占位） |
|---|---|---|
| 确定 | 有无某指标变化、干预是否有效（动物可检验） | 确定[表型]大鼠脑内[指标]变化，确定[干预]对[表型]有无影响 |
| 阐明 | 机制、谱、通路互作 | 阐明[表型]大鼠脑[技术]代谢谱的变化，及其与[因素]的关系 |
| 探讨 | 诊断分级、转化 | 探讨[技术]对[表型]诊断及分级的作用 |

**拟解决的关键科学问题**：面上/交叉近年用疑问句，早期国自可用陈述句。每问下面 2 句：为什么传统方法不行 → 本研究拟怎么做。

- 陈述：`使用在体和离体[技术]阐明[表型]干预前后的特征性代谢谱及其变化规律。`
- 疑问：`如何实现多模态异质数据的智能整合与精准预测？` ` [疾病]相关[表型]的病理核心机制是什么？`

目标与内容不要复制粘贴：内容是步骤清单，目标是可验收命题。区/院级可以把准确率写成死数字；国自少写死数字。

## 创新：拆成两栏

几乎所有自拟正文都是 **学术思想创新** + **技术方法创新**。不要把「我们用了 MRI」当成创新。

- **思想**：在前期节点上往前推一步。用「在前期研究基础之上，提出…」。
- **方法**：针对立项里点名的技术缺口（[旧技术]不能定量 [分子] → [升级技术]；量表主观 → 影像组学/可解释 ML）。

院级 AI 稿可加第三条「可解释性 / 填补某序列专用模型空白」，仍要对应病理金标准，避免只吹网络结构。

不要写：`本研究具有创新性。` `填补国内外空白。` 也不要在创新栏重复立项综述。

## 可行性：审的人要看见三块

1. **模型成熟**：点名指南/文献推荐或自己已发表的造模。给时间点和入组规则（出现表型入组，未出现作对照）。
2. **平台点名到仪器**：`[平台]` 拥有 `[仪器]`，可进行 `[测量]`。技术路线图每个节点旁写执行单位。
3. **人**：`[PI]` 访问经历、已发 SCI 篇数（可写「其中本方向 [n] 篇」）、在研相关基金编号。一句「掌握各项实验技能，能确保课题顺利实施」太空，要跟在具体平台后面。

临床可行性另写：**病源**（「每年接诊 [疾病] 超过 [n] 例」）+ 伦理与数据安全（不写批件扫描、不写电话）。区/院级特别吃病源这一条。

## 年度计划与预期成果

- 国自/卫健委：按半年块，「完成 [n] 例造模 + 某检测」。不要一年只写「撰写论文」。
- 预期结果先写**科学命题**（定量某代谢物、阐明某通路、抑制某蛋白可减轻某表型），再写论文档次和人才培养。
- 区/院级考核可把准确率、例数写死；国自优先写科学命题。

## 临床研究方案（伦理立项前）

与标书正文不是同一份：方案要能让伦理委员判断风险，不需要把机制综述写满。

必要块：研究目的（可检验的临床问题）→ 设计（前瞻/回顾、例数）→ 纳入/排除/终止/剔除 → 干预与结局 → 数据与统计。入排用条目，不用段落。例数写在设计句：`收集[疾病]患者[n]例。` 句式见 `grant-writing.md`。

## Do / Don't

- Do：立项用机制小节标题；创新拆思想/方法；可行性点名仪器与病源；摘要五步 + 假说一句。
- Do：动物与临床两条线互相验证时，在关键问题里写清「何者贡献更大 / 能否被干预逆转」。
- Don't：把评标套话（「创新性有限」「方案过于粗陋」）写进自己的申请书。
- Don't：创新栏只重复「我们用了 MRI/AI」。
- Don't：区卫健委申请书把国自 30 页机制综述原样粘进去还不改考核指标。
- Don't：伦理临床方案里写满标书式综述；方案要入排和风险。
