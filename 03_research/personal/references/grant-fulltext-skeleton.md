## By scheme (repeated headings)

### 院级科研基金 / 申请书（例：东院院级、金山院级）
Common spine (official ZH titles kept):
1. 申请人信息 / 简表
2. 项目摘要（常限字）
3. 立题依据 / 立论依据
4. 研究内容 / 研究目标 / 拟解决关键科学问题
5. 研究方案 / 技术路线 / 关键技术
6. 可行性分析（理论 / 技术 / 人员）
7. 创新点（学术思想 + 技术方法）
8. 研究基础与工作条件
9. 进度安排 / 预期成果 / 经费预算
10. 科室 / 医院意见栏

### 国自然青年 · 报告正文（NSFC Youth style）
Official-ish major blocks seen in corpus (ZH titles are SSOT):
- （一）立项依据与研究内容
  - 1．项目的立项依据（意义、国内外现状、发展趋势；附主要参考文献）
  - 2．项目的研究内容、研究目标，以及拟解决的关键科学问题
  - 3．拟采取的研究方案及可行性分析（方法、技术路线、实验手段、关键技术等）
  - 4．本项目的特色与创新之处
  - 5．年度研究计划及预期研究结果
- （二）研究基础与工作条件
- （三）其他需要说明的问题
Keep official guideline as SSOT when drafting live applications.

### 研究生开题报告 / 提纲（金山医院课题）
Fixed spine from forms (ZH titles kept):
1．课题的立项依据（意义、国内外现状；附参考文献）
2．研究内容、研究目标，以及拟解决的关键科学问题
3．拟采取的研究方案（方法、技术路线、样本、对照、统计等）
4．课题的创新之处
5．研究计划安排表（按季度）
6．预期目标 / 可能性 / 科学意义及应用前景
7．研究基础与工作条件
8．经费预算（实验直接费用）
9．研究生导师评阅意见

### 区卫健委课题计划申请（任务）书

- 一、简表

- 三、总目标 / 特色创新 / 研究内容及拟解决关键问题
- 四、技术路线图 / 技术难点
- 五、完成形式和考核指标

### 临床研究方案（青年启动·临床课题）

- 治疗方法 / 观察指标

- 研究基础
- 完成指标

- 立题依据

- 创新之处
