# 伦理材料包自检清单

## 参数一致性

- [ ] 题目全文一致（封面题可与短标题策略统一说明）  
- [ ] PI、科室、职称、电话、邮箱一致  
- [ ] 样本量（本院/总计）一致  
- [ ] 起止日期一致  
- [ ] 方案版本号/日期 = ICF 版本号/日期  
- [ ] 登记表材料清单 = 实际文件  

## 设计一致性

- [ ] 研究类型勾选 ↔ 方案设计  
- [ ] 干预描述 ↔ 知情同意过程描述  
- [ ] 主要/次要终点 ↔ 统计与样本量  
- [ ] 入排标准 ↔ ICF 通俗表述  
- [ ] 弱势群体、年龄范围合理  

## 隐私与安全

- [ ] 保密/编码方式已勾  
- [ ] 云端/AI/外送数据范围在 ICF 披露  
- [ ] AE/SAE 报告路径写清  
- [ ] 急救措施匹配本病种风险  

## 格式

- [ ] 输出目录未覆盖原模板  
- [ ] 文件扩展名与模板一致（.doc/.docx/.xls）  
- [ ] 签名表、声明结尾仍在  
- [ ] 无大量「空白重建」导致的版式漂移  

## 检索负向

全文搜索应尽量为 0：

- 样例 PI 姓名、样例手机号  
- 样例病种关键词（若本课题无关）  
- 错误样本量（如样例 400）  

## 交付物

- [ ] `00-填写说明（未改模板格式）.txt`  
- [ ] 待签字/待补项列表
