# 伦理申请表格填报（保原版格式）

将研究方案、CRF、PI 信息填入**医院伦理固定表格模板**，输出可递交材料包。

**铁律：只替换文字，不改版式。** 禁止另起空白 Word/自由排版重做表格。

与 `radiology-ethics` 分工：后者写伦理叙述/知情同意正文策略；本 skill 负责**院内表单包填报与一致性**。

---

## 触发后工作流

### 0. 环境与输入盘点

1. 定位**原版模板目录**（常名：`填写好`、`伦理模板`、`伦理材料`）。
2. 定位科学材料：研究方案（html/md/docx）、CRF 变量表、PI 信息 txt、既往数据说明等。
3. 用 UTF-8 列出文件名（Windows 中文路径优先 Python `os.walk`）。
4. 抽取样例已填内容，识别：医院名、伦理办联系方式、表单栏目结构、旧课题痕迹。

### 1. 先规划，后执行（默认必须）

在改任何正式表格前，输出规划供用户确认：

| 项 | 内容 |
|----|------|
| 润色后题目 | 与设计一致（干预/观察、人群、终点） |
| PI/科室/电话/邮箱/职称 | 来源文件 + 缺失项 |
| 研究类型 | 干预 / 观察 / 其他；是否含孕妇等弱势群体 |
| 样本量与期限 | 数字与起止日期 |
| 版本号/版本日期 | 方案与 ICF 一致（如 V1.0 + 日期） |
| 输出目录 | 默认 `填写好_<PI>_<短题>`，**不覆盖**原模板 |
| 文件清单 | 与模板一一对应 |
| 待补项 | 简历学历、团队、GCP、签字等 |

用户明确同意后再写文件。若用户说「直接做/按你的建议跑」，可执行，但仍不覆盖原模板。

### 2. 复制模板 → 输出目录

```text
复制 模板目录/* → 输出目录/
禁止：先写自由格式 docx 再假装是模板
禁止：把 .doc 改写成全新 .docx 版式（除非用户只要内容草稿）
```

### 3. 保格式填报技术路线

#### 3.1 `.docx`（python-docx）

- 遍历 `paragraphs` 与 `tables`。
- 合并单元格用 `id(cell._tc)` 去重，避免重复写。
- **写单元格**：只改首段 runs 文本，清空后续段，保留字体/边框。
- 全局替换：旧题目、旧 PI、旧科室、旧电话、旧邮箱、旧样本量、旧日期。
- 勾选框：用字符串替换 `□/☑`（如 `☑观察性`→`□观察性`，`□治疗性`→`☑治疗性`）。
- 长段落：在保留标题段的前提下替换正文；勿删签名表。

#### 3.2 `.doc`（Word/WPS COM）

- 优先 `Word.Application`；环境可能是 WPS，保存失败时 `taskkill` wps/winword 后重试。
- **查找替换**用位置参数 `Find.Execute(old, False, False, False, False, False, True, 1, False, new, 2)`。
- 表格：逐 cell 读文本 → 替换 → 写回（`Range.MoveEnd(1,-1)` 再赋 `Text`，避免破坏单元格结束符）。
- 方案长文：按**章节标题**定位，替换两标题之间的正文（`Range(start,end).Text`），**保留标题**。
- **一次只稳妥打开/保存一个 doc**；COM 易崩溃。
- 短串优先：`鞠帅`、电话、科室；长题目整句替换。

#### 3.3 `.xls` 登记表（Excel COM 或 xlrd+xlutils）

- 只改**数据行**单元格值，不重建表头/颜色说明行。
- 递交材料清单列写成与输出包一致的文件列表。

### 4. 内容一致性（所有表同一套参数）

建立参数表并全局使用：

```text
TITLE, TITLE_SHORT, PI, DEPT, PHONE, EMAIL, HOSP,
N, START, END, VER, VER_DATE,
DESIGN_TYPE (干预RCT / 观察队列…),
VULNERABLE (孕妇/儿童/无…),
PRIMARY_EP, SECONDARY_EP, AE_PLAN
```

科学内容从方案/CRF 提炼，避免与题目/类型矛盾：

- 干预 RCT 不可勾成纯观察（除非用户改设计）。
- 孕妇研究必须勾弱势群体「有孕妇」，年龄与产科实际一致。
- AI/云端：知情同意与方案写明脱敏、版本锁定、护士/医生审核、不替代医嘱。
- 样本量论证与主要终点匹配（率差 / 连续终点公式等）。

### 5. 自检清单（填完必跑）

对输出包全文检索：

- [ ] 无旧课题题目/旧 PI/旧科室/旧电话
- [ ] 无错误病种残留（如样例血吸虫）
- [ ] 题目、PI、N、期限、版本在 8 类文件中一致
- [ ] 研究类型勾选与方案一致
- [ ] 弱势群体勾选正确
- [ ] 急救/风险措施已换成本病种（非样例影像过敏等）
- [ ] 签名页/声明页结构仍在
- [ ] 输出了 `00-填写说明（未改模板格式）.txt`（待签字与待补项）

### 6. 交付

1. 输出目录路径  
2. 文件清单表  
3. 统一参数摘要  
4. 待用户线下：签字、科室意见、简历残缺项、团队成员  
5. 提醒：若院内系统只收空白模板，可将正文粘贴回院发空白表（仍以原格式为准）

## 典型表单包（金山医院样例结构）

详见 `references/jinshan-form-pack.md`。通用 8 件套：

0. 科研伦理审查申请材料登记表  
1. 伦理审查初审申请表  
1. 研究者发起的一般临床研究立项申请表  
2. 研究方案（观察/干预模板以院方文件名为准，**内容按真实设计写**）  
3. 知情同意书  
4. 研究者简历  
5. 主要研究者声明  
6. 课题组成员名单  

可选附件：CRF 变量表、技术说明、招募广告（若使用须伦理审）。

---

## 禁止事项

1. **禁止**为「好看」重建表格版式  
2. **禁止**覆盖用户的原版 `填写好` 目录  
3. **禁止**未确认关键参数就批量生成  
4. **禁止**在干预研究中照抄观察性样例的风险/受益表述  
5. **禁止**编造 PI 学历、GCP、团队成员；未知填「待补充」  
6. Windows 下注意杀毒/WPS 锁文件；保存失败先结束 `wps.exe`/`WINWORD.EXE` 再写  

---

## 辅助脚本

- `scripts/word_find_replace.py`：对单个 `.doc` 做保格式查找替换（COM）  
- `scripts/docx_cell_replace.py`：对 `.docx` 表格/段落做映射替换  

需要批量时调用脚本；复杂章节替换仍按本 SKILL 的「标题间替换」逻辑在会话中执行。
