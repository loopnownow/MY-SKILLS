# Base first-pass vs personal top re-loops

Short pointer. Full flow: `../runtime-flow.md`. Gates: `../gates.md`.

| | **base** | **personal / top** |
|---|---|---|
| Role | Fine-ID **first-pass** capability bodies under `NN_slug/base/` | Personal **top-layer** route/handoff/authority |
| When | Before 00 QC | After 00 QC (re-loops) |
| Examples | write-paper, peer-review, verify-refs, polish-language, humanize, revise | A03/A05/A06/A07 personal SKILL + route + handoff |

**Flow:** base fine-ID first-pass -> **00 QC** -> personal/top re-loops.

- Personal layers do not host long procedure bodies that live under `NN_slug/base/`.
- Fine IDs for stats-analysis / figures / data-processing / study-design unchanged.
- Registry `default_source` = `my-skills` (in-repo); personal layers document trigger/authority only.

**QC standards:** live in each domain `NN_slug/qc/`; `00_orchestrator/gates.md` decides WHEN / PASS-FAIL. Specialists and base first-pass do not self-invoke `qc/`.
