# Base first-pass vs advanced top re-loops

Short pointer. Full flow: `../runtime-flow.md`. Gates: `../gates.md`.

| | **base** | **advanced / top** |
|---|---|---|
| Role | Fine-ID **first-pass** capability bodies under `NN_slug/base/` | Advanced **top-layer** route/handoff/authority |
| When | Before 00 QC | After 00 QC (re-loops) |
| Examples | write-paper, peer-review, verify-refs, humanize, revise | 03/05/06/07 advanced SKILL + route + handoff |

**Flow:** base fine-ID first-pass -> **00 QC** -> advanced/top re-loops.

- Advanced layers do not host long procedure bodies that live under `NN_slug/base/`.
- Fine IDs for stats-analysis / figures / data-processing / study-design unchanged.
- Registry rows use `source: my-skills` (in-repo `NN_slug/base/`); advanced layers document trigger/authority only.

**QC standards:** live in each domain `NN_slug/qc/`; `00_orchestrator/gates.md` decides WHEN / PASS-FAIL. Specialists and base first-pass do not self-invoke `qc/`.
