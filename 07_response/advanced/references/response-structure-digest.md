## Letter skeleton (fixed order)

```text
Salutation (venue / portal; do not invent)
├─ Opening (≤1 para): thanks + what changed this round + how marked
├─ Reviewer 1
│   ├─ Comment N: <verbatim full comment>
│   │   ├─ Response: accept / partial / decline with reason
│   │   └─ Change: where (section/page/line/table/figure + quoted revised text)
│   └─ …
├─ Reviewer 2 …
└─ Optional change checklist (1:1 with manuscript edits)
```

**Per-point trio:** verbatim comment → response → change location. Declined items need **reason + basis** (literature, data, journal policy) — no bare refusal.

Editor comments (if any) go **first** (`To the Editor` / `Additional Editor Comments`).

## Unique bans (vs tighten-response package anatomy)

Already covered in `../response.md` Hard rules — **do not fork:** no invent format; comments verbatim; no invented subheadings; Track Changes; typography locked to gold.

**Also enforce (from 0doc structure):**

1. **No promised-but-undone edits.** If not changed: write decline + reason (not "we will…").
2. **No unread citations** in the letter; DOI / pages must be verified.
3. **No unpublished data or patient-identifying detail** in the letter; examples must be de-identified.
4. Format matches manuscript / gold response docx (same TNR set) — details in `Aitor-format.md`, not restated here.
