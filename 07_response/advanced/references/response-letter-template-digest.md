## Hard rule (template)

Do not invent undone experiments or numbers. Write what was changed; if impossible, write boundary + Limitation.

## Per-point four-piece (reminder)

1. Thanks by type → 2. One-line action → 3. Quoted revised text or exact number → 4. Locatable pin.
Forbidden alone: `revised accordingly` / `see revised manuscript`.

## Type stubs (copy shape only)

**A. Wording / add paragraph**
```text
Response: Thank you for the suggestion. We revised it in the [Section].
"[revised sentence or new paragraph]" ([Section-paragraph N]).
```

**B. Clarify methods / design**
```text
Response: Thank you for the inquiry. [factual answer]. We clarified it in the text.
"[clarifying sentence]" (Materials and methods-[subsection]).
```

**C. Real error (number / legend / spelling)**
```text
Response: Thank you for pointing this out. [what was wrong]. We rechecked the original data.
The correct value is [exact]. We corrected it in the text ([Table/page-line]).
```
No ornate apology paragraphs.

**D. Terminology fix**
```text
Response: Thank you for the comment. We agree that "[old]" is inappropriate.
We changed "[old]" to "[new]" for clarity for the readers.
```

**E. Limitation / bias / single-center**
```text
Response: Thank you for the comment. We acknowledge that [concern]. We revised the Discussion.
"[Limitation sentence]" (Discussion-Limitations).
```

**F. Cannot do (new experiment / missing marker / external validation)**
```text
Response: We agree that [X] is important for [goal]. However, [unavailable / design bound] in the present study.
Thus, we cannot revise the models to include [X]. We added this in the limitations.
"[Limitation sentence]" (Discussion-Limitations).
```
Offer partial evidence + cite when available. **Never invent future work as done.**

**G. Methods challenge (keep stance + soft boundary)**
```text
Response: We thank the reviewer for this comment. [why approach stands].
[what changed]. We revised [place] as follows: "[new]" ([loc]).
We acknowledge that [residual] and have stated it in the Discussion.
```

**H. Positive remark** — short accept only; do not expand the topic.

**I. Editor format** (abstract structure, keywords, references checklist) — confirm done; no fake checklist IDs.
