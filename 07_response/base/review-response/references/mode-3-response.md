# Point-by-point response

Generic letter machinery. Personal opening banks and Voice A/B stay in **A personal**.

Full protocol (atomize, three gates, journal default, checklist): [rebuttal-protocol.md](rebuttal-protocol.md).

## When to use

- Reviewer comments exist; need a point-by-point letter
- Revision note + paste-ready changed sentences (prose rewrite → `write-paper`)

## Workflow

1. Stable ID per comment (R1-1, R1-2, R2-1, …)
2. Classify: methods / statistics / writing / extra experiment / disagree
3. Map action: manuscript location + English reply; **do not invent unrun experiments**
4. Audit: every claimed change is locatable; run provenance / commitment / coverage ([response-audit-gate.md](response-audit-gate.md))
5. Action table: [action-mapping.md](action-mapping.md)
6. Tone: courteous, specific, one-to-one. Personal phrasing banks stay in A.
7. After number changes: hand off to `06_review/base/review-critique/paper-claim-audit.md`

## Letter skeleton

```text
Dear Editors and Reviewers:

Thank you for the review of our manuscript and for the suggestions. We have considered
the comments and have made the corresponding corrections point-by-point.

Modifications for Reviewer #X:
[Comment]
Response: Thank you for the suggestion. [What we changed]. [Location: p.X / Methods / Table Y].
```

One comment, one reply. When disagreeing: acknowledge the concern, then give data/literature,
and still improve the wording if possible.

## Output

```text
Skill: revise

Letter (paste-ready)

Change log / revision checklist
- R1-1 → [location] [change] [commitment]
```
