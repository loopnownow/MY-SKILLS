## Decision-type × default posture

| Decision type | Default package posture | Notes |
|---|---|---|
| Major Revision | Evidence-first work plan; central claim / stats / validation / structure first | Unresolved central evidence or integrity items block finalization |
| Minor Revision | Bounded correction; wording, citations, reporting, figure polish | Item-level evidence/ethics/integrity concerns still blocking |
| Revise-and-resubmit / transfer | Follow **editor letter** literally; do not force Major/Minor | Distinct types |
| Reject / appeal-like | **Out of default draft path** — route separately; do not write appeal as default | |
| Unknown | Local edit / audit / triage-only OK; **no** full package strategy | Ask once; do not invent decision from comment count |

## Task mode × output

| Task mode | Output | Decision gate required? |
|---|---|---|
| `triage-only` | Tracker / action map / missing inputs; no final letter | No |
| `draft` / `revision-package` | Master tracker + reviewer-separated replies (+ cover when asked) | Yes for package strategy |
| `point-by-point` (alias of draft structure) | Per-reviewer standalone replies | Yes when package |
| `cover-letter` | Editor-facing summary only | Preferred known |
| `audit` / `revise` | Findings or tightened draft of supplied text | No (local) |
| `latex-template` | Templates / filled `.tex` when requested | No |
| `appeal-like` | Route out; explain separate handling | `NOT_APPLICABLE` |
