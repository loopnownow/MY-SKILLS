# Word 编辑与交付（个人层）

## 修订

All manuscript Track Changes are owned by Aitee (05). Lee must not self-revise as default. Lee marks/comments; Aitee applies Track Changes. Decidable issues: Lee annotates for Aitee to TC-fix and does not apply the body revisions as default. Undecidable issues: Chinese 批注 body plus attached English suggested wording and/or suggested literature. Victor owns citation-verify (Lit05/Lit06) and supplies suggested literature for comments when needed. call/require 03 citation-verify — do not self-certify lit.

- 稿件正文的修订由 **Aitee（05）** 落地。Lee（06）默认只批注、不自行修订。可决定的问题写成给 Aitee 的 TC-fix 批注；定不了的问题用中文批注正文，并附英文建议措辞和/或建议文献（文献由 Victor 供给）。
- 下面的修订模式是 **Aitee 落修订** 时的操作，不是 Lee 自己改稿的默认。
- 所有对 `.docx` 的修改 **一律修订模式（Track Changes）**。
- **用户手改优先（仅 Word）。** 若当前句与代理上次写入的句子不同，视为用户修改。要再动那段，先问用户；禁止擅自改回。此条 **不** 适用于 HTML、PDF、脚本。
- 不明处：先 **批注（作者 A）** 或问用户；不无痕直接改、不擅自 Accept/Reject 修订。
- **保留原稿前页信息：** 若文中已有通讯作者、基金、伦理（Date/NO）、作者单位等，**禁止**用实验室默认/模板句覆盖；只在用户点名时改。缺项用批注问，不填默认值。

## 文件

- **尽量不新建文件**；优先在用户指定的现有终稿上修订。
- **中间文件尽量不产生**；若必须产生，任务结束后移入 `0del`（本机常见 `D:\0Grok\0del`）。
- 除非用户点名，否则不要另做备份副本。
- Aitee 用 Track Changes 改过、或 Lee 只批注审过 Word 后，在该课题 **`ref/manuscript-revision.md`** 追加记录（日期、文件、已修订 / 只审核 / 未动 / 未决）。后一轮不得再润、再审已记录段落，除非上游数字变了、用户点名，或未决批注被授权落地。Lee 的记录默认是「只审核」，不是「已修订」。

## 语言与版式

- 期刊信封：**英文**。给用户看的总括/内部备注/QC：**中文**。
- **禁止修改 Word 格式。** 修订已有 `.docx` 只改文字（Track Changes / 批注）。不要改样式、字体、字号、对齐、缩进、段前段后、文本前后间距、行距、文字方向、分节、页边距、表格几何。用户手改的格式同样保留。
- 新写段落若必须带格式（用户点名排版，或空白新稿）：Times New Roman，12 磅，行距 1.5，两端对齐，从左到右，文本前后 0，段前段后 0。结构细则只在 `05_manuscript/personal/Aitor-format.md`。
