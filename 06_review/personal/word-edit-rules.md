# Word 编辑与交付（个人层）

## 修订

- 所有对 `.docx` 的修改 **一律修订模式（Track Changes）**。
- **用户手改优先（仅 Word）。** 若当前句与代理上次写入的句子不同，视为用户修改。要再动那段，先问用户；禁止擅自改回。此条 **不** 适用于 HTML、PDF、脚本。
- 不明处：先 **批注（作者 A）** 或问用户；不无痕直接改、不擅自 Accept/Reject 修订。
- **保留原稿前页信息：** 若文中已有通讯作者、基金、伦理（Date/NO）、作者单位等，**禁止**用实验室默认/模板句覆盖；只在用户点名时改。缺项用批注问，不填默认值。

## 文件

- **尽量不新建文件**；优先在用户指定的现有终稿上修订。
- **中间文件尽量不产生**；若必须产生，任务结束后移入 `0del`（本机常见 `D:\0Grok\0del`）。
- 除非用户点名，否则不要另做备份副本。
- 05/06 改过或审过 Word 后，在该课题 **`ref/manuscript-revision.md`** 追加记录（日期、文件、已修订 / 只审核 / 未动 / 未决）。后一轮不得再润、再审已记录段落，除非上游数字变了、用户点名，或未决批注被授权落地。

## 语言与版式

- 期刊信封：**英文**。给用户看的总括/内部备注/QC：**中文**。
- **禁止修改 Word 格式。** 修订已有 `.docx` 只改文字（Track Changes / 批注）。不要改样式、字体、字号、对齐、缩进、段前段后、文本前后间距、行距、文字方向、分节、页边距、表格几何。用户手改的格式同样保留。
- 新写段落若必须带格式（用户点名排版，或空白新稿）：Times New Roman，12 磅，行距 1.5，两端对齐，从左到右，文本前后 0，段前段后 0。结构细则只在 `05_manuscript/personal/Aitor-format.md`。
