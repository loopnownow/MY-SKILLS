# 评别人的标书（国自等）— Voice A

**这是评别人的国自 / 面上 / 青年 / 交叉 / 原创 / 目标导向。不是写自己的申请书。**

- 写自己的立项 / 开题 / 方案 / 摘要 → `grant-writing.md` + `bundles/radiology-design` + `bundles/radiology-frontier`（Voice B）。
- 英文期刊 peer review / 投稿前预审 / 回复审稿人 → `06_review`。不要用 Please clarify 英文祈使来填国自栏。
- 两套口癖**禁止混用**：此处的「创新性有限」「可行性欠佳」不得写进自己的申请书。

占位只用 `[Title]` `[疾病]` `[技术]` `[n]` `[PI]`。不要把申请人假说、通路、未刊患者表、伦理批件、电话写进技能或输出库。

先**一句话复述申请在做什么**（用申请人自己的术语，不要扩写新机制），再评创新 / 可行 / 基础。

## 系统五栏（面上 / 常规；照栏填写）

1. `请简述申请项目的主要研究内容和申请者提出的科学问题或假说`
2. `请评述申请项目的预期结果及其科学价值和意义`
3. `请评述科学问题或假说是否明确，是否具有创新性，并予以说明`
4. `请评述研究内容、研究方案及所采用的技术路线是否能验证所提出的科学问题或假说，方法的逻辑性、可行性如何`
5. `请评述申请人的研究能力（研究经历、水平等方面）；是否具备完成该项目的研究条件（材料、样本、设备等）`

其它：`其它意见或修改建议`

档位：

- 综合评价：A 优（4）/ B 良（3）/ C 中（2）/ D 差（1）
- 资助意见：A 优先资助 / B 可资助 / C 不予资助
- 熟悉程度：熟悉 / 较熟悉 / 不熟悉

规则：综评 A/B 时资助只能优先或可资助；C 可选可资助或不予；D 只能不予。

## 目标导向 / 交叉 / 原创 变体（近年单）

- `请评述该申请项目是否面向经济社会发展需要或国家需求背后的基础科学问题。请详细阐述判断理由。`
- `请评述申请项目所提出的科学问题的创新性与预期成果的科学价值。`
- `请评述该申请项目的研究基础与可行性；如有可能，请对完善研究方案提出建议。`
- `请针对创新点详细评述申请项目的创新性、科学价值以及对相关领域的潜在影响。`
- `请结合申请项目的研究方案与申请人的研究基础评述项目的可行性。`
- `请评述申请人的创新潜力与研究方案的可行性。` / `多学科背景和研究专长`
- `该申请项目的研究思想或方案是否具有新颖性和独特性？`
- `该申请项目的研究内容是否具有原创性并值得鼓励尝试？`

仍先一句话复述，再按该栏的问题答。不要把面上五栏的标题硬套进交叉单。

## 评语口癖（可复用；已去申请人科学内容）

**简述栏（中性转述）**

```
申请者拟使用[技术]对[对象]进行[研究]，以[验证/探讨][科学问题]，为[临床/转化目标]提供[依据]。
```

**创新 / 科学问题**

- `该申请项目有具体的技术指标，预期结果有一定的创新及科学价值。`
- `该项目的科学问题比较明确，但创新性有限。`
- `该项目的科学问题比较明确，具有创新性。`
- `科学假说比较明确，但关键科学问题阐述尚有不足。`
- `假说的证据链不够完善，科学性欠佳。`
- `立项依据泛泛而谈，没有形成一个良好的研究假设。拟解决的科学问题范围过大。`

**方案 / 可行性**

- `该项目研究内容目标较为明确，研究方案和采用技术路线比较合理，有可行性。`
- `研究方案合理，研究内容明确，技术路线清晰，具备完成该项目的可行性。`
- `研究方案过于粗陋，可行性欠佳。`
- `现有的方案无法证明该研究的假设。`
- `关键性的研究基础不足，完成可行性差。`

**申请人能力 / 条件**

- `申请人具有较好的研究能力。但前期研究结果显示均为临床研究，未详细阐述是否具备完成[动物/分子]实验的研究条件。`
- `申请人具一定的研究能力，但未显示较好的前期研究基础。`
- `不足之处在于前期尚没有与该项目相关的论文发表。`
- `申请人研究基础较为薄弱。` / `代表性高质量论文成果较为欠缺。`
- `团队具备多学科背景。` / `研究团队配备有待进一步完善。`
- `不具备[AI/分子影像/动物]研究的基本条件，可行性不高。`

**其它意见（格式与可执行建议）**

- `标书书写中有错别字。`
- `立项依据中未对引用文献进行标注。部分标点符号的格式不统一。`
- `建议进行样本量估算，增加科学依据，确保研究具有足够的统计效能。`
- `强化盲法设计与偏倚控制。`
- `建议申请者加强前期研究，加强训练科研设计的合理性与严谨性。`
- `预算说明中材料费及检测费的计算依据不够详细。`
- `建议把前期工作基础制成组图。`
- `可进一步完善前期实验，为向临床转化提供依据。`

## 填写顺序

1. 简述（申请人原术语，一短段）
2. 科学问题是否明确、创新是否成立
3. 方案 / 路线能否验证假说；逻辑与可行性
4. 申请人能力与完成条件（材料、样本、设备）
5. 可执行修改建议（格式、样本量、盲法、预算依据、组图）
6. 综评 + 资助意见（遵守档位规则）

语气可以比英文 peer review 更直，但仍对事不对人：不写申请人姓名、单位、未发表数据、机制图细节。

## Do / Don't

- Do：按系统栏回答；口癖可复用，科学内容必须来自**当前这份**申请，不要从记忆补通路。
- Don't：把申请书机制图、未刊患者表、姓名/单位、电话、伦理批件写入技能或粘贴到公开仓库。
- Don't：用 `06_review` 的英文审稿套话填国自栏。
- Don't：把 Voice B 的「确定 / 阐明 / 探讨」目标三档或中英摘要骨架写成评语。
- Don't：编造评分理由去凑 A/B。一项弱（创新 / 价值 / 基础 / 可行）就按弱项写。
