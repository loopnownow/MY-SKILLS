# 方法升级怎么写进立项 — Voice B（写自己的）

**把方法升级写进立项依据，而不是另起炉灶、也不是只堆在创新栏。**
评别人的国自 → `grant-review.md`（Voice A）。选题是否够新、期刊格局 → 本 bundle 其它文件；本章只回答「升级后的方法如何嵌进标书立项」。

占位：`[Title]` `[疾病]` `[表型]` `[技术]` `[n]` `[PI]` `[假说]`。不写未刊患者表、伦理扫描、电话、通路全文。

## 升级链（方法词，不是旧假当新）

写立项时按**当前**方法代际选词。不要倒着写：早期稿不能把尚未开展的技术写成已完成基础。

| 代际 | 方法词（写进立项的技术缺口 → 本研究） | 立项里怎么用 |
|---|---|---|
| 基线波谱 | 1H-MRS / 在体+离体 MRS | 作为已有读出；同时点名缺口：敏感性/特异度低，**无法对 [分子] 定量** |
| 升级一 | 超极化 13C-MRS / 代谢流示踪（底物 → 产物） | 针对上一行缺口：对 [分子] 做定量、示踪 [A]→[B] 的过程 |
| 升级二 | 多模态影像 + 可解释机器学习 | 针对量表主观 / 单模态不够：异质数据整合与表型预测；金标准仍要病理或量表 |

链要写进**立项小节**（机制节点标题下的技术缺口段），创新栏只收「针对该缺口换了什么方法」一句，不要在创新栏重写综述。

## 立项里的写法（嵌进去，不另起章）

1. **小节标题用机制节点**，不用方法名。方法是证据，不是章节名。
2. 在「主流学说及其缺口」或紧随前期工作之后，用一短段钉死技术缺口：
   - `[技术]敏感性、特异性低，且无法对[分子]进行定量。`
   - `目前通常采用[量表]协助诊断，缺乏客观评估手段，容易受到主观因素影响。`
3. 「本研究要做什么」承接缺口：无创 `[升级技术]` ± 动物/细胞验证，而不是突然冒出一个与立项无关的新平台。
4. 创新两栏与立项对齐：
   - 方法栏 = 立项里点名的缺口的对策（1H-MRS 不能定量 → 超极化 13C；量表主观 → 影像组学/可解释 ML）。
   - 思想栏 = 机制往前推一步，不是「我们用了 MRI」。

## 可套的立项收束（占位）

```
如果能探寻[代谢节点]，示踪[A]到[B]的过程，有望早期发现[表型]，并进一步揭示发病机制。
我们拟使用无创的[升级技术]，检测[对象]的[读出]。通过比较[因素]与[表型]的相关性，并使用[对照模型]加以验证。
```

2022 起可在摘要里各用一句钉死（国自栏很短，这两句值钱；全文见 `grant-writing.md`）：

```
技术上拟创新性使用[技术]对[分子/表型]进行定量。
理论上创新性提出[分子]通过[通路]导致[细胞事件]，最终导致[表型]。
```

## 关键科学问题（方法升级之后）

疑问句适合面上/交叉：

- `如何实现多模态异质数据的智能整合与精准预测？传统统计方法难以同时处理包含[临床/代谢/炎症/影像]的高维异质数据。本研究拟基于机器学习算法，构建具可解释性的跨模态预测模型。`
- `[疾病]相关[表型]的病理核心机制是什么？目前尚不清楚多系统异常如何协同作用。本研究拟通过整合[组学A]、[组学B]与[影像]数据，揭示[轴]的动态互作机制。`

陈述句适合早期/青年：`使用在体和离体[技术]阐明[表型]干预前后的特征性代谢谱及其变化规律。`

## 与 frontier 其它文件的分工

- `frontier-themes.md` / `idea-to-question.md`：方向是否新、数据是否撑得住、期刊要什么验证。
- **本文件**：已经决定走 MRS → 超极化 13C / 代谢流 → 多模态+ML 时，**句子写在立项哪一段**。
- 不要把 Voice A 评语（「创新性有限」）或英文期刊 Please clarify 写进立项。
