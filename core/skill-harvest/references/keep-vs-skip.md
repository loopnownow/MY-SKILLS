# Keep vs skip

## Keep (skill material)

A fact is keepable only if **all** of these hold:

1. The user stated it more than once, or locked it as a rule (“以后都这样 / 做成技能 / 记住”).
2. It will apply to a **future** project, not only one folder.
3. It is a method, naming, layout, validation, or file-hygiene rule — not a sample size or AUC.
4. It is not already the single source of truth in the route map.

Examples that belong: English clinical labels; exclude-then-analyze; `VAL_MODE` trio; no Inclusion box on Figure 1; overwrite `Manuscript_<结局>_house.docx` in place.

## Skip (not a skill)

- One project’s *n*, AUC, ethics Date/NO, author list, file paths of a single endpoint
- Pure `cd`, empty sessions, “可以的 / 你决定”
- Tool install/uninstall (Grok Bridge), one-off folder tidy
- Subagent batch rebuilds that only apply house format already written down
- A second copy of a rule that already lives in `Aitor-format.md` / `figure-engine` / `data-impute`

## Other skill packs

When scanning `~/.agents/skills`, Downloads zips, or `skills_export`:

- **Absorb** a missing *mode* or script into the matching 00–06 bundle.
- **Do not** register the imported pack as a new top-level skill.
- Lab voice / house format wins over generic academic wording.
