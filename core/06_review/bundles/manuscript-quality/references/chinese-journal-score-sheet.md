# 中文杂志审稿单（A–F / 分项打分）— 单独模板

仅当邀请来自**中文期刊纸质/系统审稿单**时用本文件。

**不要**把本模板的分项打分、A–F 档、或「并无新意」一类冲词写进英文 peer review。英文走 [`mode-2-prereview.md`](mode-2-prereview.md) §2.5 + [`merged/radiology-prereview/personal-review-style.md`](merged/radiology-prereview/personal-review-style.md)。毕业论文评阅走 [`thesis-review.md`](thesis-review.md)。

不要把英文长 Methods 清单整段贴进「学术评语」。分数/等级放本单；具体改法写「综合评审意见 / 对稿件的具体意见」，3–10 条即可。

不收录未刊题目、作者名、伦理号。下面是**空白结构**。

---

## 1. 《磁共振成像》早期单（1–5 分项 + A–F）

内容审查情况（括号内 1～5 分，低～高）：

```text
论文题目：规范切题（  ）。
摘要：与文章内容相符（  ）；结构层次清晰（  ）。
材料与方法：方法先进（  ）；设计合理（  ）；资料可靠（  ）；统计方法正确（  ）。
结果：与主题相符（  ）；数据可靠（  ）；表格恰当（  ）；图片信息可靠（  ）。
讨论：观点明确（  ）；论述符合逻辑（  ）；有说服力（  ）。
参考文献：时效性（  ）；可信度（  ）。
文章内容：有推广实用价值（  ）；属前沿性论文（  ）。
```

综合评审意见：按 **前言 / 材料与方法 / 结果 / 讨论** 编号，短句、直接。本单可以比英文信冲，但仍要写清作者该改什么，不要只打分。

稿件最终处理意见（A–F 择一）：

```text
A. 提前全文发表
B. 全文发表
C. 修改后全文发表
D. 修改后按短篇发表
E. 修改后再审
F. 退稿
```

## 2. 《中国医学计算机成像杂志》近年学术审稿单（勾选 + 分级）

内容审查（打勾，每行四档择一）：

```text
政策法规： 1.无错误  2.有错误  3.需研究  4.有泄密
文章题目： 1.切题  2.不明确  3.文题不符  4.较繁琐
内容提要： 1.简明完整  2.欠完整  3.不精炼  4.不合要求
实验设计： 1.有创造  2.合理  3.欠合理  4.有错误
技术方法： 1.有创新  2.有改进  3.常规方法  4.不可信
实验结果： 1.有新发现  2.有新见解  3.资料性工作  4.有疑问
数据处理： 1.可靠  2.计算有误  3.方法不当  4.样本不足
图表内容： 1.适当  2.与文字重复  3.与文字不符  4.欠自明性
讨论部分： 1.论点明确  2.论证不足  3.不切题  4.繁琐冗长
参考文献： 1.引用适当  2.引用过多  3.引用不足  4.文献陈旧
```

评语三行：

```text
科学性： 1.强  2.较强  3.一般  4.较差
先进性： 1.首创  2.有创新  3.有新见解  4.重复性工作
可读性： 1.简明通顺  2.欠通顺  3.欠简炼  4.繁琐冗长
评估分级： 1.A级  2.B级  3.C级  4.D级
```

处理意见（四档，不是英文 Major/Minor）：

```text
1. 采用
2. 补充后采用
3. 修改后复审
4. 不采用
```

背面「对稿件的具体意见」：先一段肯定（设计、数据、方法点到为止）→ 主要不足 / 次要不足编号。可中英各一段（综述类邀请常这样）；中文段不扩写英文没有的新批评。

## 3. 院内 / 中文学术评语（无 A–F 表时）

先等级或分数，再一段肯定贡献，再「不足之处」约 3 条。不要贴英文 20 条 Methods 清单。

不足三条可套（无患者级细节）：

1. 样本例数有限，需扩大以提高可重复性。
2. ROI 均为人工勾画，难以避免人为因素。
3. 今后可探索自动勾画，并与其他中心合作做外部验证。

处理意见用杂志自己的档（采用 / 修改后复审 / 修改后再审），不要写成英文 peer-review 的 Blocking / Major / Minor。
