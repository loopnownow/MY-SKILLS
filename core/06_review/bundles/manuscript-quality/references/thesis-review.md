# 毕业论文评阅（院内 / 学校学位论文）

与英文期刊 peer review **分开**。不要用 [`mode-2-prereview.md`](mode-2-prereview.md) §2.5 的 Opening → Major → Abstract/Methods 信封，也不要写成 20 条英文 Methods 清单。中文刊 A–F 审稿单走 [`chinese-journal-score-sheet.md`](chinese-journal-score-sheet.md)。国基标书评审不在 06_review（那是 `03_research`）。

来源：自审毕业论文评阅 16 份，全部中文。只收骨架和套话，不抄学位论文题目、学号、导师名、未发表数据表。

---

## 何时用

用户说「评阅毕业论文 / 学位论文 / 是否同意答辩 / 硕博评阅表」——走本文件。  
用户说 peer review / 写审稿意见 / 英文审稿 ——走 mode-2 §2.5，**不要**把下面套话译成英文 Major Comments。

---

## 骨架（按表格变体填，不要改成英文 Major/Minor）

```text
1. 论文选题及意义
2. 主要成果及创新之处  /  成果的意义
3. 总体评阅意见（理论基础、独立科研能力、书写规范）
4. 不足之处 + 修改建议
5. 是否同意答辩
6. 分项分数：选题 / 文献综述 / 研究成果 / 科研水平 / 论文规范
```

硕博评阅表常见提示语（照填）：

- 评阅人对学位论文的总体评阅意见（请根据评价表中各项评价指标写出详细评语，论文若涉及学术不端行为请务必指出）
- 请评阅人指出学位论文的不足之处，并提出修改建议（意见为须作重大修改或不同意答辩的，烦请详细说明）
- 是否同意该生参加学位论文答辩

专业学位表另有：选题来源于实际 / 能解决实际问题；熟悉程度：熟悉 / 一般 / 不熟悉（建议退回）。

博士高风险审核登记另有：选题意义 / 逻辑构建 / 专业能力 / 学术规范；学生对专家意见逐条回答。

---

## 总体评语模板

肯定段（可压缩，点到为止）：

```text
该课题在[领域]进行了[设计类型]研究，具有[临床/实际]应用价值。对国内外研究动态的掌握较为全面，评述恰当，对所要解决的问题的目的及意义论述清楚。作者掌握比较坚实的理论基础和相关专业知识，具有独立从事科学研究工作的能力。论文书写规范、表达清楚；概念清晰、分析严谨；数据真实、结论正确。
```

短版选题：

```text
论文选题有新意，有实际应用价值，结构安排合理，论证充分，格式符合规范要求。
```

专业学位短版：

```text
该选题来源于实际，能解决临床实际问题；文献资料丰富、新颖；研究方法及设计方案恰当可行；研究步骤科学规范；工作量达到相应学位要求。
```

---

## 不足 / 建议（2–4 条可执行；不要写患者级细节）

- 本研究样本量较少，实验组与对照组样本量分布不均匀。
- 建议在之后的研究中对自动分割/人工修正做可重复性分析。
- 方法内未明确说明如何定量获取[测量]，通过手动勾画感兴趣区？
- 数据来自不同机型，扫描参数不同，未经过标准化处理，可考虑 ComBat 等消除批次效应。
- 总体样本量较小，可进一步扩大样本并做外部验证。
- 文中统计值 P 的书写格式不统一，建议统一。
- 未与现有标志物/方法对比，创新点的独特性和优势不明确。

---

## 结论档

- 是否同意答辩：同意
- 是否同意答辩：同意略作修改后进行答辩
- 总体评价：优秀 / 良好 / 合格；创新点：良好 / 较强

不要在评阅里写 Reject / Major revision 英文档。

---

## Do / Don't

- Do：先选题意义 → 不足 2–4 条可执行建议 → 明确是否同意答辩。
- Don't：把英文期刊那套 Opening / Major Comments / 20 条 Methods 搬进来。
- Don't：在评阅里复述未发表数据表。
- Don't：把本文件用于 NSFC 标书或英文 peer review。
